# 共演 Polyphony

共演让教师把已有课件直接编成可授课的课堂，在原页上加入讲解、例题和互动。教师可以放映、收集作答，并在课后回看学生的理解过程。

- 单机演示：[共演演示室.html](共演演示室.html) · [示例课件](示例课件/光电信号读出.pptx)
- 独立实验：[Polyphony-Playlab.html](Polyphony-Playlab.html)
- 联机课堂、AI 配置和部署：[使用说明](studio/README.md) · [系统架构图](Polyphony-System-Architecture.pdf)

使用 Node.js 22 或更新版本启动联机课堂。在浏览器访问 http://localhost:4188。

    cd studio
    npm start

在 studio/ 运行 npm test 可执行回归测试。
