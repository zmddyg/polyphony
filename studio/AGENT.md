# 共演智课 Agent 工程规范

本文约定课程编排、原稿迁移、模型调用与课堂交付的行为。离线运行时在
`dist/core/agent-spec.mjs` 中使用同一组精简规则、页数预算与版式建议。

## 课程编排与工程护栏

| 职责 | 负责组件 | 交付条件 |
| --- | --- | --- |
| 规划课堂 | 教学编排 Agent | 给出章节顺序、全课符号约定、逐页任务、推导过程、实例、配图和排版决策。依据学科特点设计互动卡点。 |
| 校验事实引用 | Harness | 以实际页面文字确定性编号 `M1..Mk`。验证互动及各分支引用的编号和逐字引文。 |
| 校验公式与互动 | Agent 工具、Harness | 以离线 KaTeX 编译公式并检查示意图标签和正文密度。用 `safe-expr` 验证表达式、变量、函数和区间内有限值。 |
| 修复与发布 | Harness | 对结构或引文问题提供有限校验反馈并逐页复验。双轮状态机沙箱依次验证首轮、公开、分支、改答与结束。 |

Agent 在课程编排中选择教学方式。Harness 决定数据能否交给课堂运行。
教师在上课前复核学科事实、推导条件以及图像与授课内容的对应关系。

## 长程编排

面向 6–48 页的大学课堂。任意支持页数使用同一编排流程，采用教师指定的课堂节奏和互动密度。先建立学习目标和先修条件，再推进概念、推导、实例、理解检测与迁移总结。每页聚焦一个可讲授的任务，正文建议在 320 字内，通常使用 2–3 个结构块，最多 4 个。讲者备注承担过渡、追问和补充细节。

首次出现变量时给出意义、单位和适用区间。同一符号在后续章节沿用。物理光学采用 $e^{-i\omega t}$、$\tilde{U}=A e^{i\varphi}$ 和 $I=\tilde{U}^*\tilde{U}$。C 语言给出标准保证、实现定义和未定义行为的边界，代码样例交代对象生命周期、指针有效范围以及必要前置条件。人文内容明确给出论点、可定位的证据、推理过程和适用限度。行内式标作 `$...$`，独立等式写入 `formula`，JSON 中的 LaTeX 命令使用双反斜杠，例如 `"\\frac{a}{b}"`。

1. **课程蓝图**。确定标题、符号约定、章节页段、逐页教学任务、原型节奏及候选卡点。
2. **分批写页**。按章或小节将 3–5 页排为一批，串行传入全课符号表、已提交的概念摘录和原型序列。工具校验与单页提交会实时更新教师预览。终止信号随模型与检索请求传递。
3. **全卷自审**。快速决策模型复核符号、公式、图文平衡、原型变化和互动分布，最多定点精修 3 页。
4. **互动合成与验证**。优先放在容易混淆的分界、关键推导之后及迁移之前。标准密度的 8、24、48 页分别安排 2、6、10 处。紧凑密度接近每 6 页一处，高频密度在前 24 页接近每 3 页一处。合成后的互动通过证据核验和双轮状态机试跑。

模型或校验导致失败时，回执记录具体页码与脱敏原因。教师可按批或选定失败页继续编排，已提交的页面与通过校验的互动继续可用。未设置模型时使用本地结构化备课框架。

## 编排工具

| 能力 | 工具与结果 |
| --- | --- |
| 开放许可配图 | `search_media` 接收检索词和备选词，返回最多 4 张候选的编号、标题、宽高比及许可。提交时以候选编号选择图片，成稿内嵌图片和署名。 |
| 数学绘图 | `plot_math_chart` 验证表达式和区间，每条曲线采样 81–121 点，返回可复用的图表编号。 |
| 页面校验 | `validate_math_and_diagram` 报告块结构、KaTeX、示意图标签截断和可见文字密度问题。 |
| 资料查证 | `lookup_reference` 查询 Wikipedia 和 OpenAlex，保留文本摘要和来源。不可达时返回原因，课堂编排继续推进。 |
| 提交与精修 | `commit_slides` 逐页校验和提交。`revise_slide` 更新获准改写页的指定字段，并复验后提交。 |

工具循环优先发送原生 `tools`，把工具结果以 `tool_call_id` 对应回传。接口拒绝工具字段时自动切换到 JSON Action，使用 `call_tool` 和 `final` 互通。教师端展示每次调用的状态、结果与可重试问题。

四种协议按证据择用。概念诊断寻找同选异因，逐行找茬定位代码、流程和推导中的第一个问题，参数沙盒要求有可解析的原式和有效取值范围，证据权衡用于存在多种可辩护判断的情形。同一课程可组合适用的协议，避免重复测试同一个能力。

## 原稿迁移

| 模式 | 行为 |
| --- | --- |
| 原页无损活化 `preserve` | 默认模式。保留原页画面、顺序、图像、备注和已有的补充页，用 Harness 在适合的原页加入互动。 |
| 原页升级与拓展 `enhance` | 保留原页。Agent 根据原页的 `M1..Mk` 依据增加原理图、推导、对照表或例题，支持同套工具与定点自审。讲者备注标注原稿页码和引用编号。 |
| 平台原生重构 `rebuild` | 以导入的文字、公式和表格为事实依据，按来源编号复用提取插图，缺图页可按教师设置检索补图。采用同一套蓝图、逐批提交和全卷自审。无 API 时按原稿内容分块重排。 |

如导入只得到原页图版，则把原页图版作为原稿图像回用。可用的独立嵌入插图优先呈现，带裁剪信息的插图仅使用可见图像。来源缺少可提取文字时，课堂只能依据图版开展观察。
重构时把未上屏的原文放入该页可展开的文稿。回执记录原稿页数、原稿片段及图片数量、复用图片数，以及超出单页文字容量的摘录数。

## 视觉与版式

- 光路、电路、算法、流程和架构用声明式 `diagram`。用短节点标签、清晰连接线和适当的方向表达可核对的关系。
- `cover` 提出本讲问题，`section` 标明章节入口，`derivation` 呈现推导，`split-compare` 对齐两侧比较维度，`example` 提供可检验实例，`summary` 汇总可迁移结论。避免连续三页使用同一原型。
- 真实实验装置、显微照片或可观察现象适合开放许可配图。教师开启联网后，检索 Wikimedia Commons、Wikipedia 与 Openverse 的开放许可图片。下载校验后内嵌，并保留作者、许可和来源。可通过 `POLYPHONY_MEDIA_SEARCH_ALLOWLIST` 收紧服务端下载域名范围。配图不可用时可采用声明式示意图。
- 有正文或公式并配图时，`split-right` 左文右图。需要从图开始观察时用 `split-left`。宽幅图可用 `media-top`，横排关系图可用 `diagram-focus`。宽表、双栏代码和单一阅读任务使用 `single`。其余场景交由 `auto` 适应内容与屏幕宽度。

## 双层模型

开放兼容主模型负责章节蓝图、深层讲解、完整推导与复杂互动。快速决策模型负责卡点筛选、自审精修、互动结构修正、课中即时分析和难点诊断。两层可搭配 OpenAI、DeepSeek、Qwen、Gemini 或校园网关，单模型设置可同时承担两项职责。组件区分模型超时、拒绝、截断和参数错误，并把脱敏结果传回教师界面。

模型把课件文字和第三方媒体元数据视为教学数据。模型输出先进行双密钥检查，再进入任何校验回执或课件结构。教师难点诊断和口播建议通过教师鉴权通道返回，留在当前教师界面。
