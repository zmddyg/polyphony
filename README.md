# 共演智课 · Polyphony V4.0

共演智课把讲义、学生作答与讨论放在同一页。教师可以迁移原稿或生成一套课件，带着可核对的备课回执开讲，再将本课学情带回原页。

## 多阶段教学编排 Agent + 五阶段 Harness 工程护栏

- **真工具调用排课 Agent** 配置模型后，6–48 页课件共用同一流程，默认 10 页也先规划章节、记号与互动节奏，再串行成稿。支持 Chat Completions 原生工具调用和 JSON Action。五项工具能力涵盖多源搜图、精确数值绘图、公式与示意图校验、百科与学术参考查证、逐页提交与修订。
- **开放兼容的双层模型** 开放兼容主模型编写课程蓝图、学科推导和讲义，快速决策模型优先负责互动筛选、全卷审查与课中诊断。教师能在编排面板追踪工具结果、预览已成稿页、查看脱敏失败原因并重试对应页面。
- **原稿三模式迁移** 原页活化保留顺序和画面。升级追加与原稿引文关联的拓展页，重构利用原文、公式、表格和提取插图重新编排，并可为缺图页补充开放许可配图。
- **离线 KaTeX 与六种视觉原型** 两份单文件均内嵌 KaTeX 和 20 款 WOFF2 字体。封面、章节页、推导、对比、例题、总结按教学任务选用，公式、代码、表格和声明式示意图随课件交付。
- **五阶段 Harness 工程护栏** 依次完成解析或大纲规划、节奏与卡点预算、契约合成、核验与限次自修、双轮沙箱预演。按 `M1..Mk` 核对原文引句，验证 KaTeX 与页面结构，以 `safe-expr` 按表达式采样曲线，再通过状态机检验双轮互动。

## 打开课堂

- **单机离线** 打开 `共演智课-离线平台.html`。用现代浏览器在 `file:///` 下直接备课、预演和复盘，支持可提取的 PPT/PPTX、共演课件 JSON 与粘贴讲义。教师、投影和学生席位在同一浏览器内联动。
- **多设备联机** 解压后双击 `启动V4共演.cmd`，或在 `polyphony-studio/`（源码目录为 `studio/`）运行 `node server.mjs`。需要 Node.js 22 或更新版本。开课后可分享课堂码或加入链接。PDF 原页由 Python + PyMuPDF 渲染，PPT/PPTX 原页渲染使用 PowerPoint 或 LibreOffice + Python UNO。
- **讲台同屏与复盘** 用「🖥+📱 同屏演示」切换学生 A、学生 B 和手机遥控。课后按页查看首轮、二轮与代表性理由，批量回流高错页至备课记忆库。教师可复制战报 Markdown 或导出可打印教研复盘 HTML。
- **学生个人复习单** 在速查抽屉或结课页下载个人 HTML，离线打开或打印存 PDF。复习单汇集本课已解锁速查卡、本人两轮作答及参考解析、待复习和存疑页。
- **带走课件** 在备课预览的「更多」下载共演课件 JSON，可携带讲义正文、公式、图片与互动到其他电脑。原稿与草稿可从浏览器的备课版本库续接。

## 试点指标与比赛演示

课堂试点战报汇总参与总人数、作答理由填写率、首轮和二轮平均正解率、净跃迁百分点、配对改答率、互动页数及最高存疑讲授页。全卷优先使用真实作答。模拟样本带来源标记，参赛文档的 11/27 栏位可用真实课堂的 Markdown 战报填入。

打开 `共演智课-单文件离线演示版.html`，直接进入完整备课中枢。按 **D** 或点击右上角「🎬 示范课与导览」，载入 8 页 C 指针原稿，预览或同屏开讲三门完整课例，亦可直达 C 指针 P7、物理光学 P5、大学英语 P8 和双轮演练后的全卷复盘。

交付包的 `比赛演示/` 含参赛介绍 PDF、决赛 PPTX、示例课件和 `系统截图/`。三门原生课件分别为 C 指针 12 页、物理光学 10 页、大学英语 10 页。三份原生课件 JSON 可在正式平台直接导入，另附三份编译校验回执。

## 联机设置

- 服务默认监听 `0.0.0.0:4188`。跨设备使用同一网络，必要时用 `POLYPHONY_PUBLIC_ORIGIN` 指定邀请二维码中的可访问地址。
- `POLYPHONY_TEACHER_PASSPHRASE` 可为开课与服务端课件导入启用教师口令。讲台「更多」中的手机遥控二维码五分钟内可一次性领取。
- 主模型与快速决策模型可独立配置。支持 OpenAI、DeepSeek、Qwen、Gemini 和校园网网关的 Chat Completions 兼容端点。可在教师「设置」的当前会话填写密钥，或通过服务进程环境传入 `POLYPHONY_AI_*` 与 `POLYPHONY_FAST_AI_*`。无模型时可使用本地备课框架和分析。
- 教师可在备课时启用开放许可搜图，图片下载校验域名、内容和许可后内嵌。参考查证使用 Wikipedia 与 OpenAlex，连接失败时回执给出原因，编排可继续。Windows TUN 的保留地址段仅允许已获信任的 HTTPS 图库域名解析使用。
- 默认使用 JSON 存储，`POLYPHONY_ROOM_FILE` 指定存储路径。`POLYPHONY_STORAGE=sqlite` 可启用 SQLite WAL，建议使用 Node.js 22.13 或更新版本。
